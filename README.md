# C Programming Dynamic Quiz

This is a console-based quiz application written in C. It uses file I/O to dynamically load questions, options, and correct answers from an external text file,
meaning the quiz can be updated without modifying the C source code. 

## How to Compile and Run
You must have a C compiler (like GCC) installed. 
1. Open your terminal or command prompt.
2. Navigate to the folder containing these files.
3. Compile the program:
   ```bash
   gcc quiz.c -o quiz
